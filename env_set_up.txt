！！！！To avoid running terminal commands every morning, you can use a Lifecycle Configuration (LCC). This is a script that AWS runs for you every time the instance starts up.
Step 1: Create the LCC Script
1. Go to the AWS Sagemaker Console 
2. Click Lifecycle configurations.
3. Click Create configuration.
4. Name it: reconnect-recsys-env.
5. Under Start notebook, paste this:
#!/bin/bash
set -e
# Re-register the kernel, so it appears in the dropdown menu automatically
/home/sagemaker-user/anaconda3/bin/python -m ipykernel install --user --name hybrid_recsys_env --display-name "Python 3.11 (SageMaker V2)"

Step 2: Attach it to your Profile
1. In the SageMaker Console, go to Domains.
2. Click on your User Profile.
3. Under Environment, find Lifecycle configurations.
4. Add the reconnect-recsys-env script you just made as a Start-up script.
